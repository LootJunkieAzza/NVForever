**Test build, not an official release.** NVForever v0.8.0 for Linux, rebuilt on Ubuntu
24.04 so it runs on systems with glibc 2.39 or newer, such as the Steam Deck. The official
v0.8.0 Linux build needs glibc 2.43 and stops at once on older systems, with no window and
no log. The game is the same v0.8.0 code; only the build machine changed. This build never
sends player reports.

**You need your own copy of Fallout: New Vegas (1.4.0.525, base game + all DLC).** No game
data is included. Unpack anywhere outside the game folder and run `./nvforever.sh --data
<your Fallout New Vegas folder>` (or `./nvforever-launcher`). If it still does not start,
run it from a terminal (Konsole in Desktop Mode) and send the lines it prints, together
with the output of `ldd --version | head -1`.
