The third NVForever pre-release: everything merged since v0.2.0 (earlier on 2026-10-18),
about 20 pull requests. The main news is **Mod Organizer 2 support**.

**You need your own copy of Fallout: New Vegas (1.4.0.525, base game + all DLC).** No game
data is included. Unpack anywhere outside the game folder and run `nvforever.exe` (or
`nvforever.cmd`; `./nvforever.sh` on Linux). The first start asks for your game folder and
remembers it, and the game opens on the main menu. `README-release.md` in the archive
explains the rest. NVForever never writes into the game folder or
`Documents\My Games\FalloutNV`; its own home is `Documents\My Games\NVForever`.

## New since v0.2.0

**Mods**
- **Mod Organizer 2:** add `nvforever.exe` to MO2's executables (the drop-down beside
  **Run**, then **<Edit…>**, **+**, **Add from file…**) and start it from there. NVForever
  loads the plugins ticked in MO2's profile, in MO2's order, with the active mods' files in
  `Data` by MO2's priority, and runs on the game folder MO2 manages, also when that is a
  copy of the game, as modlists such as Viva New Vegas use. MO2's profile INIs and saves are
  not used. `docs/mod-organizer-2.md` in the repository has the details.
- Without a mod manager nothing changed: NVForever's own
  `Documents\My Games\NVForever\plugins.txt` (`*` = on).
- NVSE plugins (`.dll`) do not run in NVForever; mods that need NVSE may not work yet.

**NPCs and combat**
- Knockdowns: PushActorAway throws actors from the source, explosions knock people down,
  and SetUnconscious holds a lying actor down until cleared.
- Look with the rotate-body flag turns the whole body to the target.
- Fighters show the angry combat face.
- Actors placed by scripts can be shot, and leveled ones carry their pick's items.
- Script packages take one slot and replace each other as in the original; disabled
  references still run their scripts, as the original game was observed to do.

**World, interface and sound**
- The flashlight follows the head in third person.
- Sounds slow down with VATS mode and the death camera.
- The Pip-Boy's miscellaneous statistics are counted (26 of 43); SetScale is drawn and
  collided.
- Help boxes scroll long texts, with a scroll bar.

**Stability**
- Cached models, parts and textures nothing draws are released (a memory leak on long
  trips), and stray entity commands no longer crash the game.

## Not built yet

The player is never knocked down, the Caravan card game, slot machines, the companion
wheel, the tutorial menu, and credits. The full list, ranked by what blocks a playthrough,
is in `docs/outstanding.md` in the repository.
