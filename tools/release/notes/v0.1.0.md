The first NVForever release: everything that builds as of 2026-10-13, as a pre-release.

**You need your own copy of Fallout: New Vegas (1.4.0.525, base game + all DLC).** No game
data is included. Unpack outside the game folder and start with `nvforever.cmd --play`
(Windows) or `./nvforever.sh --play` (Linux); `README-release.md` in the archive explains
setup.

## Programs

- **nvforever**: the game. `--play` is a playable slice: walk the Mojave with collision;
  talk to NPCs in the original's dialogue menu with their recorded voices; NPCs follow
  their AI packages, detect you, fight, flee and take cover; shoot, strike and throw;
  companions such as Boone follow you through doors and fight with you; pick locks, hack
  terminals, use aid items, wait and sleep; crime and karma are tracked; the HUD, Pip-Boy,
  inventory, barter and container menus come from the game's own menu files; music,
  sounds and radio play. `--graphics enhanced` gives an optional enhanced look.
- **nvf-viewer**: NIF meshes with their DDS textures, KF animations.
- **fnvtool**: `setup`, `paths`, and archive/plugin inspection as JSON.

## State by layer

| Layer | Scope | State |
|---|---|---|
| 1 | BSA reader, ESM/ESP parser, load order, schemas | done |
| 2 | NIF, DDS, KF assets, viewer | done |
| 3 | World and rendering | done, with known gaps (exterior lighting and clouds, effect shaders, depth of field) |
| 4 | Core simulation, collision, physics, play | done; 3 accepted physics residuals |
| 5 | Scripting | done; 80 script functions remain stubs |
| 6 | Gameplay: AI, dialogue, combat, followers, crime, aid | mostly done |
| 7 | Interface, audio, saves | mostly done |

**Not started:** saved games, the main menu, VATS, levelling up and perks, repair and
crafting, the Caravan and casino games. Full per-system map: `docs/status.md`.
