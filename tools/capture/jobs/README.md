# Hand-written capture jobs

`fnv.capture.steps/1` jobs written by hand for diagnostics and follow-up questions (the
scenario jobs are generated by `capture_steps.py` and not kept here). To re-run one, copy
it into the capture directory's `jobs\` folder (default `C:\fnv-private\capture\jobs\`),
load the save its `start` text names and press End in game. Results and what they
settled: docs/spec-notes/layer4-captures.md §2.

They contain only script text and FormIDs (no game data). Forms are built with
`BuildRef <GetModIndex> <decimal local FormID>`, as docs/spec-notes/xnvse-capture.md §5
requires.
