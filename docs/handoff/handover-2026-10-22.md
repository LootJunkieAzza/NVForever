## 5. Things a later session should know

- **Outside the scripts' turn the game's world is not attached.** In engine systems
  `Game::world` is a placeholder, and `functions::base_of` returns `None` there. Engine
  code must take the base from `SimState::base_of` (and read `GameData`), or wrap the call
  in `script::with_world`. #580 found this when its VATS and blood checks silently did
  nothing.
- **`PlaceAtMe` from the script test aid places at the player.** It ignores the distance
  argument.
- The crosshair now logs `reticle: prompt "…" on "…"` on every change (#584), which smoke
  scenarios can match.
