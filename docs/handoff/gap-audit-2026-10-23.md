# Gap audit: script functions, scripted logic, NIF data, ESM records (2026-10-23)

The owner's playtest list 7 item 44: "audit all data types in esm, all stubs and scripted
logic to see if we have missed anything since the latest round of changes and systems
built, spot check the nif formats for any more values that are not decoded/used via the
new engine". Worker W9, branch `claude/l7-audit`, from origin/main 301f062d.

Out of scope here, because the laptop's "Handover PR continuation" session owns them: the
ESM gap audit's groups 6 (detection), 7 (visuals) and 8 (unparsed records: CAMS/CPTH, DOBJ,
RGDL, REGN RDSD), its low-impact list
([esm-gap-audit-2026-10-21](esm-gap-audit-2026-10-21.md)), and the smoke scenarios
combat-dogs and cook-cook-camp. Combat AI (W4), the Pip-Boy (W2) and performance (W8)
were being worked on at the same time and are only noted here.

Ranking: **A** can stop a quest or a companion from working; **B** is noticed in normal
play; **C** is rare, cosmetic or only shows in places.

## 1. Method

- **Stubs**: `fnvtool script stubs` over the ten masters (14,907 script units).
- **Partial behaviour**: read the implemented functions' notes for "not built", "only
  kept", "not modelled" and similar; decompiled every unit (`fnvtool script decompile`)
  and searched the calls that reach those paths (AddPerk with forTeammates, RemovePerk on
  NPCs, SetVatsTarget, trapUpdate). Rechecked the "wrong" and "open" rows of
  [script-function-coverage](../design/script-function-coverage.md) §6 against main.
- **NIF**: `fnvtool nif nodes` over the base archives only (`Fallout - Meshes.bsa`,
  `Update.bsa`, `Fallout - Misc.bsa`; the add-on archives hold a lab holdout): every block
  type and extra-data name by files. Then each of the 229 schema block types was searched
  for in the engine and the crates outside `fnv-nif`'s codec, and `fnvtool nif anim` gave
  which interpolators the sequences use.
- **ESM**: `fnvtool esm inventory` of FalloutNV.esm against the 2026-10-21 audit's text and
  the consumers' record signatures.
- **Smoke**: the tool scenarios (all 21), and the failures handover-2026-10-22 §3 and
  handover-2026-10-21 §2 name, run once on main's code (this branch before its changes).

priority row 11 (critical-hit effects) is built (`Game::apply_crit_effect`,
